# Lock Thought

A quiet time capsule for ideas worth keeping.

This repository contains the static page source for [lockthought.com](https://www.lockthought.com).

## Run locally

Open `dist/index.html` in a modern browser or serve the `dist` directory with any static web server.

## Prototype notes

- Capsules are encrypted in the browser and stored in that browser's local storage.
- The passphrase is not saved or sent. There is no account, sync, or recovery.
- The time lock is an interface boundary, not tamper-proof enforcement.
- This is an experimental prototype and has not received an independent security audit.
- Visit analytics send anonymous view and heartbeat events; capsule content and passphrases are not included.
